## 0. 一句话定位

> 本仓库**不是**"肿瘤进展预测"模型。它是一套面向三维增强 MRI 的**变化有界、结构可证、逐位可复现**的医学影像可控合成框架，外加一套**生成阶段隔离审计协议**。

我们如实报告一个**否证性结论**：在当前数据与权重下，两阶段扩散采样器对最终输出**不产生影响**——把它整体替换为冻结采样、常数潜变量甚至他例结果，输出**逐位不变**。本仓库给出该现象的根因诊断（解码器 Sigmoid 饱和）、完整的受控对照证据，以及一条**已验证可修复**的路径（重建 PSNR 15.99 → 29.30 dB）。

**把"不能做什么"讲清楚，和把"能做什么"讲清楚同等重要。** 这是本项目的方法学主张。

## 1. 主要结论

### 1.1 五条可证明、可机器精度核验的命题

时间推进被写成命题而非经验设定，全部在 51 例测试集上复核：

| 命题 | 内容 | 闭式/理论值 | 实测（51 例） |
| --- | --- | --- | --- |
| 命题 1 | 负荷—权重仿射性：混合权重可解释为归一化体积进度 | — | 最大相对残差 **1.02×10⁻¹⁵**（机器精度 ε=2.22×10⁻¹⁶） |
| 命题 2 | 凸组合恒等式：逐刻度帧严格为两端点凸组合 | — | 最大相对偏差 **1.92×10⁻⁷**（单精度 ε=1.19×10⁻⁷），51/51 成立 |
| 命题 3 | 指数律相邻帧增量的 Lipschitz 上界 | 0.019454577 | **0.019454598**（相对偏差 1.11×10⁻⁶） |
| 命题 4 | 生长律权重相对线性权重的最大偏差 | 连续上确界 0.186513 | 双精度 **0.186505833**／单精度 0.186505824（相对偏差 4.40×10⁻⁸），位置第 56.30 刻度 |
| 命题 5 | 轨迹有界性 ‖x(t)−x₀‖ = w(t)·‖x_N−x₀‖，且生成模块贡献 ≤ 0.028 | s·c = 0.028 | 全幅上确界均值 0.0215 |

### 1.2 生成阶段隔离审计（否证性结论）

在 51 例测试集上把生成模块整体替换为七种情形，其余环节完全不变：

- **①完整两阶段 DiT ②换随机种子 ③冻结采样 ④打乱病例 ⑤常数潜变量** —— 五项的四项指标在 51 例上**逐位完全相同**（逐例最大绝对差 0）。
- **⑥直接使用源图 ⑦输入纯噪声** —— 也落在同一区间内（Soft IoU 0.9821 / 0.9801）。
- 逐例跨七情形的极差在 51 例上的均值仅 **0.0034 / 0.0048 / 0.0188 / 0.0129**。

**根因**：自编码器潜变量幅值过大（均值 **11.43**），解码器末层 Sigmoid 在 **99.92%** 的体素上饱和，解码输出近似常数（标准差 0.0012）；随后候选核内 **99.97%** 的体素残差超过裁剪阈值 0.08，对称裁剪退化为符号图 `clip(Δ)=0.08·sign(Δ)`，不同生成器给出的符号分布完全一致（一致率 1.000）。

**结论**：本文报告的指标刻画的是"生长律时间推进 + 结构保持后处理"构成的**确定性主链**，**不能**作为扩散采样器生成能力的证据，也**不构成**疾病进展的临床准确度。

### 1.3 一条已验证可修复的路径（试点）

保持网络结构、优化器、学习率、批大小、轮数、种子与主结果权重全部不变，仅做两处披露性改动——潜变量按 EMA 统计量标准化、解码器末层由 Sigmoid 换成有界非饱和的 Hardtanh(0,1)，**单机 4.5 分钟**重训即得：

| 指标 | 修复前 | 修复后（试点） |
| --- | --- | --- |
| 整幅重建 PSNR | 15.993±1.497 dB | **29.299±1.318 dB** |
| 解码输出标准差 | 0.0010 | **0.1447** |
| 候选核内裁剪饱和比例 | 99.97% | **34.98%** |
| 后处理后候选核内替身最大差 | 0.000 | **0.0433** |

即：**"结构保持指标不反映生成能力"是权重层面的工程缺陷，而非方法框架的固有性质。** 但同一试点也显示，核内/环带对比度仅 0.990（自编码器往返 1.412、随机潜变量 1.706），**不具备病灶定位性**——修复后可生成 ≠ 可用于临床预测。

## 2. 方法概览
源体数据 x₀ (1×64×64×64)
   │
   ├─ 3D 卷积自编码器 ──► 潜变量 z (4×16×16×16) ──► 重建
   │        └ 确定性潜空间自编码器（无显式均值—方差分支），损失 = MSE + 0.5·L1 + 0.25·梯度项
   │
   ├─ 条件 DiT（噪声预测器）── 嵌入 64 · 2 块 · 4 头 · patch 2×2×2 · 512 token · T=200 · β 1e-4→0.02 线性
   │
   ├─ AdaNI 两阶段推理 ── stage1 按时间跨度选噪声起点（≤3→0.20T，3–7→0.50T，>7→0.80T）
   │                       stage2 以 0.15T 低噪声起点二次细化纹理
   │
   ├─ 结构保持后处理 ── 残差 ±0.08 裁剪 → 仅在病灶候选掩膜内叠加
   │                     整体去噪 0.35 · 回填高频纹理 0.24 · 病灶曝光压低 0.22
   │
   └─ 生长律参数化时间推进 ── w(t)=(V(t)−V(0))/(V(N)−V(0))，取代按刻度线性分配的权重
                             支持指数 / Gompertz / logistic-Fisher-KPP，可由等效体积倍增时间 T_d 参数化

**时间口径**：`N` 与 `t` 是**生成网格上的刻度**，不是临床随访时间点。刻度只决定权重曲线的采样密度与轨迹长度，其与真实病程的对应关系需要纵向随访数据标定。因此本文轨迹只承载病灶形态沿生长律**单调演化的趋势信息**，不构成对具体病程时间的预测。`T_d = 45.0 天` 是**生长律参数**，**未由队列标定**。

## 10. 已知局限（请在使用前阅读）
1. 无纵向随访真值：数据集为单时间点横断面影像，不含同一患者的纵向随访。网格刻度是生成条件，不是经临床验证的时间预测；T_d 未由队列标定。
2. 扩散采样器被旁路：当前权重下生成阶段对最终输出无贡献（§1.2），相关指标不能解释为扩散生成能力。
3. 候选掩膜远大于真实病灶：候选核占脑区 24.39%±1.88%，专家标注病灶仅占 0.20%±0.41%，两者 Dice 仅 0.0071±0.0184（最宽松参照 0.0164±0.0278）。掩膜基于启发式统计特征，不是分割标注。
4. 空间局域性有限：病灶候选区之外仍存在约六成的相对变化幅度。
5. 越出本文支持范围的用途：本框架不用于临床诊断、治疗决策或个体化病程预测。它提供的是可审计的可控合成能力与一套可复用的审计协议。
